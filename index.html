Featured Data Analysis Project 01

E-Commerce Sales Analysis: Excel, SQL, Python and Power BI

An end-to-end analysis of 5,000 e-commerce orders from 2024 to 2025, done in four tools: cleaning and querying in SQL, exploratory analysis in Python, pivot reporting in Excel and an interactive Power BI dashboard.

What I worked on

Removed 8 duplicate orders with window functions and handled missing values in SQL, then analysed revenue by region, sales trends, top products and discount vs profit using Pandas, Matplotlib and Seaborn. Built Excel pivot tables with conditional formatting and a Power BI dashboard with KPI cards showing ₹32.69M revenue, ₹11.44M profit and 5,000 orders.

Technologies

SQL Server T-SQL Python Pandas Matplotlib Seaborn Excel Power BI
SQL Analysis  ·  Python EDA  ·  Excel Analysis  ·  Power BI Dashboard
Featured Data Analysis Project 02

Funnel Drop-off Analysis

An event-level analysis of a signup and checkout funnel with 200 users, built to find where users drop off and recommend what to fix.

What I worked on

Calculated unique users and conversion at each of five stages. Handled a data quality gap where 50 users had a later step logged without the earlier one, by using each user’s furthest stage. Found the biggest leak: 96 users lost between details filled and email verified, a 50% conversion. Added a funnel chart, time to convert, automated drop-off flagging and a written recommendation note.

Technologies

Python Pandas Matplotlib Funnel Analysis Data Quality

Internship Project 03

Price Comparison Application

A Python-based application designed to extract product information from uploaded images and compare product prices from online shopping platforms. A user uploads a photo of a product, the application reads the text on it using OCR, processes that text to work out what the product is, and then looks up prices on online shopping platforms so everything can be compared in one place without typing a search.

What I worked on

Worked with image upload, OCR, product text extraction, data processing and price comparison functionality. My work covered the upload flow in Flask, extracting readable product text from images with Tesseract OCR, cleaning and processing that text with Transformers-based tools, and collecting prices from shopping platforms through web scraping so the results could be shown side by side.

Technologies

Python Flask Tesseract OCR Transformers Web Scraping

Final Year Project 05

Gamified Environmental Educational Learning Platform

A gamified educational platform designed to make environmental learning more interactive for schools and colleges. Instead of only reading static material, learners move through lessons and quizzes, earn XP, climb ranks, build daily streaks and compete on a leaderboard, which gives them a reason to keep coming back and keep learning.

What I worked on

This included the flow from lesson to quiz, the scoring that awards XP, rank progression as XP grows, streak tracking for consistent use and the leaderboard that compares learners. The platform is built as a web application with HTML, CSS and JavaScript.
